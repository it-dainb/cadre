# S01: `agentId` at `agent.spawn` equals later event ids

- **Assumption / source:** A5 (WE S1)
- **Mode:** headless
- **Design:** DESIGN §14 (live smoke list)

## Purpose

`agentId` at `agent.spawn` equals later event ids.

## Steps

Headless runs go through the harness only (Docker, user directive):

```bash
R=~/research/claude-dgtx
RUN="env SPIKE=$R/cadre OUT=/tmp/cadre-smoke/out WORK=/tmp/cadre-smoke/work $R/harness/run.sh"   # plugin = /work/spike in the container
mkdir -p /tmp/cadre-smoke/out /tmp/cadre-smoke/work
```

1. Scaffold a seeded repo first: `(cd /tmp/cadre-smoke/work && bash $R/cadre/evals/execute-p1-ts/scaffold.sh)` (git repo, `dev`, approved plan `p-p1`).
```bash
$RUN -p 'Use the Agent tool once with subagent_type cadre:explorer to list the files in the repo root, then stop.' --plugin-dir /work/spike --model haiku --debug-file /out/S01.log
```
3. In `/out/S01.log` (or the mod event log) compare the `agentId` returned by `agent.spawn` with `e.agentId` on that agent's `tool.check`, `tool.call`, `turn.step`, `turn.complete`.

## Expected

All ids equal. A mismatch breaks the per-agent fence: stop and re-evaluate (A5).

## M0 status

PASS (probe, host). `agent.spawn.out` agentId `ac5a8cf…` equals the later `e.agentId` values. ADR 0001 S1.
