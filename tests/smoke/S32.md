- **Assumption / source:** A14
- **Mode:** headless

```bash

RUN="env SPIKE=$R/cadre OUT=/tmp/cadre-smoke/out WORK=/tmp/cadre-smoke/work $R/harness/run.sh"   # plugin = /work/spike in the container
```

```bash
$RUN -p 'Spawn cadre:worker on the seeded task.' --plugin-dir /work/spike --model haiku --debug-file /out/S32.log
```
3. Inspect `cadre:cost:<agentId>` in the log / `/cadre status` cost line.
