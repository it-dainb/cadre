# S18: bd latency under 3 workers + L3 fingerprint cost

- **Assumption / source:** A6
- **Mode:** host
- **Design:** DESIGN §14 (live smoke list)

## Purpose

bd latency under 3 workers + L3 fingerprint cost.

## Steps

1. In a scaffolded repo: run 3 parallel `bd update <id> --set-metadata=k=v` writers, time `bd show` and `bd ready`.
2. Time `git status --porcelain=v2 -z; git rev-parse HEAD; git for-each-ref` in a small and a large repo.

## Expected

`bd show` ≈ 0.4 s; parallel writers ≤ 3.4 s, no errors; fingerprint 10 ms small, 0.5 s on 4.7k files.

## M0 status

PASS. ADR 0001 S18. Keep `store.timeoutMs` 45 s.
