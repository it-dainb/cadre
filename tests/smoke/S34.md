# S34: `{result}` + `context` on `TaskCreate` reaches main

- **Assumption / source:** A16
- **Mode:** headless
- **Design:** DESIGN §14 (live smoke list)

## Purpose

`{result}` + `context` on `TaskCreate` reaches main.

## Steps

Headless runs go through the harness only (Docker, user directive):

```bash
R=~/research/claude-dgtx
RUN="env SPIKE=$R/cadre OUT=/tmp/cadre-smoke/out WORK=/tmp/cadre-smoke/work $R/harness/run.sh"   # plugin = /work/spike in the container
mkdir -p /tmp/cadre-smoke/out /tmp/cadre-smoke/work
```

```bash
$RUN -p 'TaskCreate a task with subject "x" and quote any plan rules you were given.' --plugin-dir /work/spike --model haiku --debug-file /out/S34.log
```

## Expected

The `{result}` context (plan rules, `missing:` line) appears as an attachment on main.

## M0 status

PASS. ADR 0001 S34.
