## Purpose

## Steps

Headless runs go through the harness only (Docker, user directive):

```bash
R=$(git rev-parse --show-toplevel)   # repo root
RUN="env SPIKE=$R OUT=/tmp/cadre-smoke/out WORK=/tmp/cadre-smoke/work $R/harness/run.sh"   # plugin = /work/spike in the container
mkdir -p /tmp/cadre-smoke/out /tmp/cadre-smoke/work
```

