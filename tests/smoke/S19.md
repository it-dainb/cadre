# S19: `bd create -s draft --deps --stdin --metadata=`

- **Assumption / source:** S19
- **Mode:** host
- **Design:** DESIGN §14 (live smoke list)

## Purpose

`bd create -s draft --deps --stdin --metadata=`.

## Steps

1. `bd create -t task -s draft --stdin --allow-empty-description --metadata='{"cadre.package":"."}' <<<'$weird '"'"'quotes'"'"' --flag'` in a `bd init`ed dir.
2. `bd ready` must not list it; `bd update <id> -s open` approves; try `--deps blocks:<id>` and `--deps blocked-by:<id>`.

## Expected

Draft stored intact, excluded from `bd ready`. `blocks:<id>` means "this blocks id" (reverse).

## M0 status

PASS with a gotcha: use `blocked-by:` or a bare id. ADR 0001 S19.
