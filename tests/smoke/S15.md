# S15: `cwd` rewrite to an out-of-repo worktree is honoured

- **Assumption / source:** A2
- **Mode:** headless
- **Design:** DESIGN §14 (live smoke list)

## Purpose

`cwd` rewrite to an out-of-repo worktree is honoured.

## Steps

Headless runs go through the harness only (Docker, user directive):

```bash
R=$(git rev-parse --show-toplevel)   # repo root
RUN="env SPIKE=$R OUT=/tmp/cadre-smoke/out WORK=/tmp/cadre-smoke/work $R/harness/run.sh"   # plugin = /work/spike in the container
mkdir -p /tmp/cadre-smoke/out /tmp/cadre-smoke/work
```

1. Scaffold a seeded repo first: `(cd /tmp/cadre-smoke/work && bash $R/evals/execute-p1-ts/scaffold.sh)` (git repo, `dev`, approved plan `p-p1`).
```bash
$RUN -p 'Spawn cadre:worker on the seeded task and have it run pwd.' --plugin-dir /work/spike --model haiku --debug-file /out/S15.log
```

## Expected

Agent `pwd` is `<wtRoot>/<repoKey>/<task-branch>`, not the repo.

## M0 status

PASS. ADR 0001 S15.
