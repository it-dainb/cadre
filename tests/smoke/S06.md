# S06: `mcp__cadre__*` tools visible in a background subagent, absent from agents whose `tools:` omit them

- **Assumption / source:** WE S6; S41 (MCP grant)
- **Mode:** headless
- **Design:** DESIGN §14 (live smoke list)

## Purpose

`mcp__cadre__*` tools visible in a background subagent, absent from agents whose `tools:` omit them.

## Steps

Headless runs go through the harness only (Docker, user directive):

```bash
R=~/research/claude-dgtx
RUN="env SPIKE=$R/cadre OUT=/tmp/cadre-smoke/out WORK=/tmp/cadre-smoke/work $R/harness/run.sh"   # plugin = /work/spike in the container
mkdir -p /tmp/cadre-smoke/out /tmp/cadre-smoke/work
```

1. Scaffold a seeded repo first: `(cd /tmp/cadre-smoke/work && bash $R/cadre/evals/execute-p1-ts/scaffold.sh)` (git repo, `dev`, approved plan `p-p1`).
```bash
$RUN -p 'Spawn cadre:worker in the background on the seeded task and have it print its tool list, then stop.' --plugin-dir /work/spike --model haiku --debug-file /out/S06.log
```
3. Spawn a custom agent with a `tools:` list lacking `mcp__cadre` and ask it to call `report`.

## Expected

Worker sees `report`, `inspect`, `run_check`; the custom agent does not.
