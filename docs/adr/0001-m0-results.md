# ADR 0001: M0 spike results (smokes S1–S50, assumptions A1–A30)

Status: accepted · Date: 2026-10-10 · Design: `design/DESIGN.md` v2.5 §14, §15 row M0, §16.1
Pin: Claude Code **2.1.295** · bd **1.3.1** (npm `@beads/bd`; the design asks ≥ 1.3.0) · bubblewrap 0.9.0 (host) / 0.8.0 (container)

## How it was run
- Probe mod: `spike/` (`hooks/register.ts`, config-driven by `spike/cfg.json`, one file per event under `spike/logs/ev/` merged by `spike/mklog.sh` into `spike/logs/probe-<run>.jsonl`; run scripts `run.sh` host, `crun.sh` container). Debug logs: `harness/out/*.debug.log` (container runs) and `spike/logs/*.debug.log` (host runs). Scratch fixtures: `spike/scratch/`.
- **Host runs** (before the user moved live tests into Docker): S1, S15, S17, S26, S31a–c,e, S32, S34, S35, S36, S39, S40a/b, S43, S44, S23–S25 (first pass), S28. **Container runs** (`harness/`, image `cadre-harness`): S13b, S16, S23 repeat, S31d, S36 re-check, S41, S45, S47, S48, S49. Host-only (no Claude): `bd` smokes, `bwrap` S27/S42/S46, validate/test.
- **Container-vs-host differences** (`harness/run.sh` flags): Docker's default seccomp blocks user namespaces (`bwrap: No permissions to create new namespace`), so `--security-opt seccomp=unconfined apparmor=unconfined` is required. Docker also masks `/proc`, so Claude's own sandbox (bwrap `--unshare-pid` + fresh `/proc`) failed with `Can't mount proc on /newroot/proc` until `--security-opt systempaths=unconfined` was added. With those three flags the S23 result is byte-identical to the host. Other differences: bwrap 0.8.0 vs 0.9.0 (neither has overlay); `~/.claude` must be pre-created writable in the image (compaction wrote `~/.claude/projects`: `EACCES` before the fix); session transcripts live in a mounted dir so `--resume` works across `--rm` runs. Only `~/.claude/.credentials.json` is mounted from the host user.
- Model: haiku for every run. Total spend: a few dozen tiny runs (single-digit dollars at most).

## S44 numbers (haiku, tokens per first step of a fresh agent; `read`/`create` = cache read/creation)
Source: `spike/logs/probe-s44a.jsonl`, `probe-s44idle.jsonl`, `probe-s43.jsonl`, `probe-s32.jsonl`, `probe-s47.jsonl` (`turn.step.done` lines).
| Case | cache read | cache create | note |
|---|---|---|---|
| Fresh worker, cold | 0 | 8,666–8,669 | prefix (system + tools + prompt + brief) fully written |
| Fresh worker, 2nd–3rd of the same type within minutes | 3,134–6,459 | 2,212–5,543 | cross-worker prefix hit **36–74 %**; ≈3.1k tokens (base system + shared tool prefix) is the stable floor, the rest depends on warm 1h entries |
| Different agent type (`w` vs `p`) | 0–3,118 | 5,539–8,669 | only the engine's base prefix is shared |
| Resume (SendMessage) immediately | 6,459 | 2,299 | transcript reused; ~26 % of a fresh write |
| Resume after **~335 s idle**, 5 m TTL agent (`$.agent.register`) | 2,708 | **5,994** | cache expired: rewritten (≈ cold) |
| Resume after ~335 s idle, **1 h TTL agent** (agent file) | **6,459** | 2,267 | identical to an immediate resume: cache survived |
| Fork (`subagent_type:'fork'`) | **42,688** | 2,347 | shares the whole main prefix (cheap per token, but it carries main's context, 42k here) |
| Main conversation | 1h TTL (`ephemeral_1h`), read ≈ 95 % of context turn over turn | | |

**Decisions (A28, §7):** (1) reuse beyond 5 min pays: a 5 m agent re-created ~6k tokens after a 5.5 min gap while the 1 h agent paid nothing extra; a 1 h write costs more than a 5 m one, so use 1 h for worker/tester/reviewer (waits for review/rework/human are minutes to hours) and 5 m for the one-shot explorer. (2) `reuse.cacheTtlMs` default **3,600,000** for 1 h agents (300,000 only if the 1 h route is unavailable on the account); fresh-vs-resume rule "idle > cacheTtlMs with context > 30 %" stays. (3) Prefer resume over fresh (resume ≈ 26 % of a fresh write); never use fork for task agents (it drags main's context). (4) `subagentPromptCacheTtl` (global) not proposed: the per-agent file route works. (5) Re-measure the 1h benefit on the user's real plan before M3; the docs say the frontmatter 1h is ignored without usage credits.

## Plan B decision (S45, §3.5)
**Not adopted.** The normalized-input fence (per-tool input fields, `realPath` via `$.fs.stat`, segment-aware root) confined Read/Write in every tried escape (`..`, absolute, symlinked file, symlinked dir, `view/../x`). Grep/Glob are not exposed by 2.1.295 here, so the absolute-pattern normalization risk (A22) does not arise. ADR 0004 is not needed; re-open if `$.tool.list()` ever lists Grep/Glob (re-run S45 with Glob `../` and `{a,../b}` patterns first).
