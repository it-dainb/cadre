Status: in progress. Sections are added by the slice that delivers them.

## H11 ui.language: partial delivery (O2)

The mechanism is present, zero translations ship. Decisions are keyed by `kind` plus the option or field `key`; `ui/tr.ts` holds the one `tr(key, en)` and the one label resolver (`pick`) used for both the shown labels and the answer match. Only option labels, the decision title shown and field labels go through it; the free-text brief keeps the English title. `ui.language` has no value beyond `en` and no settings row. `tr` is imported from `ui/**` only (`scripts/budget.mjs`, `tests/language.test.ts`). A language is a table in `ui/tr.ts`; the binding H11 text asks for a translated UI, so this is a partial delivery.
